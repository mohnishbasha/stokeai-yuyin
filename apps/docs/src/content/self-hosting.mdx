# Self-hosting

Self-hosting is not yet available. This page marks the place where the install guide will go, so links to it stay stable.

## Who it is for

Teams that need audio to stay inside their own data centre.

## Requirements

Requirements come from measured sizing in the capacity guide, not from estimates. They are added here when that guide is published.

## Licence key

A self-hosted installation runs with a signed licence key, which the service checks offline. How a key is applied is described here once the self-host edition is released.
