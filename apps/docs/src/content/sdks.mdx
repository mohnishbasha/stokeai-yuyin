# SDKs

Official clients for the Yuyin API. Both are generated from, and checked against, the same OpenAPI file as the [API reference](/reference).

## TypeScript

The TypeScript SDK is not yet published, so there is no install command to show. When it is published, this page will show the install command, a speak example, a streaming example, and how errors and retries are surfaced.

## Python

The Python SDK is not yet published either. Its runtime dependencies are kept to a minimum and the public API is fully typed. The install command is added here once the package is published.

## Reference

Every method maps to an operation in the [API reference](/reference).
