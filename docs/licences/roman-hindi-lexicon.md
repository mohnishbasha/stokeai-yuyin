# Roman Hindi lexicon, English lexicon, and n-gram model: sources and licences

Used by the language tagger (S1-T02, PRD FR-004 and FR-005). Files are in
`crates/yuyin-text/data/` and are regenerated by `scripts/tagging/build_tagger_data.py`.

| File | Content | Source | Licence |
|---|---|---|---|
| `roman_hindi_lexicon.tsv` | Roman Hindi word forms with a Devanagari reading when known | Aksharantar rows with source `AK-Freq`, plus first-party seed and variants | CC BY 4.0 (Aksharantar part), first-party for the rest |
| `english_lexicon.txt` | English word forms | First-party seed `scripts/tagging/english_seed.txt` plus generated inflections | First-party |
| `tagger_ngram.tsv` | Character trigram log-likelihood ratios | Trained on the two files above | First-party, derived from the two files above |

## Aksharantar (AI4Bharat)

- Source: <https://huggingface.co/datasets/ai4bharat/Aksharantar>, file `hin.zip`, pinned to commit
  `e418c1fc928d9f5393af33268472cf20c1891be8`. SHA-256 of `hin.zip`:
  `208c2d1b128234e6dc777b750779b4f5e6214ab43244039349b530bf9868bdaf`.
- Paper: Madhani et al., "Aksharantar: Open Indic-language transliteration datasets and models
  for the next billion users", 2022. Project page: <https://indicnlp.ai4bharat.org/aksharantar/>.
- Licence as stated on the dataset card (section "Licensing Information"): manually collected data
  is released under CC BY; mined data (Samanantar, IndicCorp) and existing sources are released
  under CC0. The Hub metadata field says only `cc`, so the card text is the authority.
- What we use: only the Hindi rows whose `source` field is `AK-Freq` (12,806 rows, 12,778 distinct
  Roman forms, 9,554 Devanagari words). Those are the manually collected, frequency-sampled
  transliterations, covered by CC BY 4.0. Attribution: "Aksharantar, AI4Bharat, CC BY 4.0".
- What we do not use, on purpose: rows from `Dakshina` (Google, CC BY-SA 4.0, ShareAlike), and rows
  from `Existing`, `Wikidata`, `Samanantar`, and `IndicCorp`. Their rights are mixed or
  unclear for embedding, so nothing from them is in the repository.

## Leipzig Corpora Collection (considered, not used)

Hindi and English word-frequency lists from the Leipzig Corpora Collection were considered for
frequency ranking and rejected. The project publishes conflicting statements (CC BY for corpora,
CC BY-NC for "data and applications") and the usage page could not be read to settle it. Unclear
rights, so not used.

## First-party data

- `scripts/tagging/hindi_seed.txt`: about 700 common romanised Hindi words and chat spellings.
- `scripts/tagging/english_seed.txt`: English vocabulary for banking, telecom, delivery, support.
- The Devanagari to Roman transliterator in `build_tagger_data.py` adds up to three spelling
  variants (for example `nahin`, `nahee`) for each Aksharantar `AK-Freq` Devanagari word. Variants
  that are English words are dropped.
- Written for this project by its authors. No third-party text, no scraped data, no model output
  trained on third-party data.

## Held-out evaluation data

`tests/data/tagging/hinglish_heldout.tsv` is original first-party text. It is not used to build
the lexicons or the n-gram model. See `tests/data/tagging/README.md`.

## Regenerating

```
python3 scripts/tagging/build_tagger_data.py
```

The script downloads `hin.zip` once into `target/tagger-data-cache/`, verifies the SHA-256 above,
and writes the three data files. Output is byte-identical on every run.

## Open item for the owner

The Hub metadata for Aksharantar says only `cc`. This record relies on the licence text in the
dataset card. If the owner wants a stricter reading, drop the Aksharantar part: the seed and
transliterator output alone is under 5,000 forms, so the 20,000-form target would then need
another permissively licensed source.
